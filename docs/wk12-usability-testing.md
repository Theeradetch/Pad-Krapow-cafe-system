## 3. รายการ Usability Issue (เรียงตาม Severity จากสูงไปต่ำ)

> ปรับจากฉบับเดิม: Issue #1 เดิมอ้างถึง "มอคค่า" ซึ่งไม่ตรงกับ Task 1 (Latte + Cappuccino) จึงเขียนใหม่ให้มาจากข้อสังเกตที่บันทึกไว้ในหัวข้อ 2 และเพิ่ม Issue #2 จากข้อสังเกตของ Task 3

### Issue #1

1. **คำอธิบายปัญหา:** หลังเลือก Cappuccino ผู้ทดสอบใช้เวลาหาปุ่มยืนยันออเดอร์ (บันทึกเวลา 0:35 ของ Task 1) ปุ่มยืนยันไม่เด่นพอเมื่อเทียบกับส่วนอื่นของหน้าจอ
2. **Task ที่เกี่ยวข้อง:** Task 1 — สั่ง Latte 2 แก้ว และ Cappuccino 1 แก้ว แล้วชำระเงินสด
3. **ความถี่:** พบ 1 ครั้งจากผู้ทดสอบ 1 คน
4. **หลักการที่เกี่ยวข้อง:** Visibility — การกระทำหลักของหน้าจอต้องมองเห็นได้ทันที
5. **Severity:** Minor — ผู้ทดสอบหาเจอเองและทำ Task สำเร็จ แต่เสียเวลา ซึ่งมีผลช่วงลูกค้าเยอะ

### Issue #2

1. **คำอธิบายปัญหา:** ผู้ทดสอบหาทางเข้าหน้ารายงานจากหน้าหลักไม่เจอในทันที ต้องเปิดเมนูย่อย 2 จุดก่อนเจอ (บันทึกเวลา 0:10–0:25 ของ Task 3)
2. **Task ที่เกี่ยวข้อง:** Task 3 — ตรวจสอบว่าเมนูใดขายดีที่สุดในวันนี้
3. **ความถี่:** พบ 1 ครั้งจากผู้ทดสอบ 1 คน
4. **หลักการที่เกี่ยวข้อง:** Visibility / Recognition rather than recall — ทางไปหน้าหลักของระบบควรเห็นตลอด ไม่ต้องจำว่าซ่อนอยู่ที่ไหน
5. **Severity:** Minor — หาเจอเองภายใน 40 วินาที

### ข้อสังเกตที่เป็นจุดดี (ไม่ใช่ปัญหา)

- Task 2: ผู้ทดสอบเห็นข้อความแจ้งเตือนเมนูหมดและเปลี่ยนไปเลือกเมนูอื่นได้เอง แสดงว่า Error message ใช้งานได้ (Error Recovery)
