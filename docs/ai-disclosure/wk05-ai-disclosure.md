# Week 05 AI Disclosure

## การใช้ AI ในการทำงาน

งาน Week 05 นี้มีการใช้ AI เป็นเครื่องมือช่วยในการทำความเข้าใจโจทย์และแนวทางการพัฒนา REST API ที่เชื่อมต่อกับ MySQL รวมถึงช่วยตรวจสอบการเขียนโค้ดและการจัดการ Transaction โดยผู้จัดทำเป็นผู้ตรวจสอบผลลัพธ์และนำมาปรับให้สอดคล้องกับโจทย์และงานที่ได้รับมอบหมาย

### ส่วนที่ใช้ AI ช่วย

1. ช่วยอธิบายแนวคิดเกี่ยวกับการเชื่อมต่อ Node.js กับ MySQL และการใช้งาน `mysql2`
2. ช่วยอธิบายแนวคิดเรื่อง Connection Pool และการตั้งค่า `connectionLimit`
3. ช่วยแนะนำแนวทางการเขียน API สำหรับดึงข้อมูลนักเรียนและค้นหาข้อมูลตาม `id`
4. ช่วยแนะนำการใช้ SQL `JOIN` เพื่อดึงข้อมูลรายวิชาที่นักเรียนลงทะเบียน
5. ช่วยอธิบายการทำงานของ Transaction เช่น `beginTransaction()`, `commit()` และ `rollback()`
6. ช่วยตรวจสอบแนวทางการจัดการกรณีลงทะเบียนซ้ำ รายวิชาเต็ม หรือไม่พบรายวิชา
7. ช่วยตรวจสอบรูปแบบ Error Response และ HTTP Status Code ที่เหมาะสม เช่น `400`, `404` และ `409`
8. ช่วยแนะนำแนวทางการทดสอบ API และตรวจสอบผลลัพธ์จากฐานข้อมูลหลังการทำรายการ

### ส่วนที่ผู้จัดทำตรวจสอบและรับผิดชอบ

ผู้จัดทำตรวจสอบว่าแนวทางที่ได้สอดคล้องกับโจทย์ Week 05 และสามารถทำงานร่วมกับฐานข้อมูล MySQL ที่จัดเตรียมไว้ โดยได้ทดลองรัน API และตรวจสอบผลลัพธ์จริงด้วยตนเอง ทั้งการดึงข้อมูลนักเรียน การเพิ่มข้อมูล การลงทะเบียนรายวิชา และการทดสอบกรณีเกิดข้อผิดพลาด

ในส่วนของ Transaction ผู้จัดทำตรวจสอบการทำงานของ `beginTransaction()`, `commit()` และ `rollback()` รวมถึงตรวจสอบว่าข้อมูลในฐานข้อมูลถูกเปลี่ยนแปลงถูกต้องตามผลการทดสอบ จากนั้นจึงนำเนื้อหามาปรับแก้และจัดรูปแบบก่อนส่งงาน

AI ถูกใช้เป็นเครื่องมือช่วยในการเรียนรู้และตรวจสอบแนวทางเท่านั้น ผู้จัดทำเป็นผู้รับผิดชอบผลลัพธ์ การทดสอบ และความถูกต้องของงานที่ส่ง
