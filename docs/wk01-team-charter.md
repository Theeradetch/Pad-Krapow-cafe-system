# แนวคิดการพัฒนา

## เลือกใช้ Waterfall Model

### เหตุผล

1. ระบบร้านกาแฟมีขั้นตอนการทำงานที่ชัดเจน สามารถวางแผนและกำหนดความต้องการได้ก่อนพัฒนา
2. สามารถแบ่งการทำงานเป็นลำดับขั้น เช่น วิเคราะห์ ออกแบบ พัฒนา ทดสอบ และติดตั้งระบบ
3. ช่วยให้ติดตามความคืบหน้าและจัดการเอกสารของโครงการได้ง่าย

ดังนั้น Waterfall จึงเหมาะกับระบบร้านกาแฟที่มีขอบเขตงานชัดเจนและต้องการดำเนินงานตามขั้นตอนอย่างเป็นระบบ
